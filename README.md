## What I work on
- **Network operations (NOC) tooling** - latency monitors, packet viewers, traffic collectors.
- **One-click server installers** - Zabbix, NetBox, NTP and rsyslog provisioned over SSH.
- **Desktop apps** with PyQt and WPF, packaged as ready-to-run Windows executables.
- **Automation and bots** - Telegram alerts, job search, report generation.
